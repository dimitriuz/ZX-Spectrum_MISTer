# Scorpion ZS-256 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Scorpion ZS-256 as a new machine mode to the ZX Spectrum MiSTer core, verified first by simulation (no hardware available yet).

**Architecture:** New machine flag from OSD Memory option value 5; mode-gated memory decode in `ZX-Spectrum.sv` (ROM window prefix `{3'b110,…}` for the four new boot.rom chunks at columns 36–39, full lower-half paging via a new `#1FFD` register, vram-mirror extension for screen banks 5/7); F11 NMI key reused as MNI; `ARCH_SCORP` added to snap_loader (z80 hw=10). All behavior verified in a GHDL simulation harness (Docker container) before any hardware flash-test.

**Tech Stack:** SystemVerilog/Verilog + VHDL (T80, tzxplayer), GHDL 4.x via Docker (archlinux base), Python for ROM tooling, iverilog NOT usable (VHDL).

**Spec:** `docs/scorpion-zs256-design.md` — read it first; this plan implements it.

## Global Constraints

- **No behavior change for existing machines** (ZX48/ZX128/+2A/+3/P128/P1024/PF1024). Every decode change is gated on the new `scorp` flag. Regression traces (Task 3 Step 1) must diff clean after every RTL task.
- **Sim-first**: no Quartus build, no hardware until Task 6 passes sim. Sim runs in Docker only (no root on host; GHDL not installed locally).
- **SDRAM physical decode** (derived, spec §3): `bank=addr[23]`, `row=addr[13:1]`, `column=addr[19:14]`, `byte=addr[0]`; bits [24, 22:20] aliased. boot.rom chunk *i* (index-0 download, base `0x150000`) → column `20+i`. Existing ROM window `{3'b101, page_rom, r}` → column `16+p` (p reads chunk p+4). New Scorpion window `{3'b110, page_rom, r}` → column `32+p`; Scorpion page_rom values **4–7** read new chunks **16–19**.
- **Scorpion paging semantics** (Fuse `machines/scorpion.c`, spec §1): page P = `{#1FFD[4], #7FFD[2:0]}`; screen bank = `#7FFD[3] ? 7 : 5`; ROM at #0000: `#1FFD[0]`→RAM bank 0, else `#1FFD[1]`→ROM2 Shadow, else `#7FFD[4] ? ROM1 : ROM0`.
- **MNI = bare F11** (user decision): in scorp mode, F11 rising edge sets `scorp_1ffd <= 8'h02` and pulses NMI. No new key bindings; do NOT touch existing F-key functions (F4–F8 = CPU speed, F9 pause, F10 MF/shadow-at-reset, F11 NMI/reset combos).
- **ROM source**: `scorp294-99f57ce1-recomended.rom`, SHA256 `f10e9daa1ff302247322b01c1ec63547e18d56a2ab3c62579f2b5c7fafd0ddeb`. Per-page SHA1s in spec §1.
- **Commit after every task.** No formatter/linter runs (FPGA repo, no tooling); do not run Quartus.
- All calculations (bit fields, offsets, columns) MUST be done with a script (`eval`/python), never by hand.

- [ ] **Step 2: Behavioral SDRAM model**

Create `sim/sdram_model.v` — behavioral MT48LC16M16A2 (16-bit DQ, 2 banks, 8192 rows × 64 columns per bank, byte-select via A[1:0] as used by the controller). Port list MUST match `rtl/sdram.sv`'s SDRAM_* outputs exactly (it drives: `SDRAM_DQ[15:0] inout`, `SDRAM_A[12:0]`, `SDRAM_DQML`, `SDRAM_DQMH`, `SDRAM_BA[1:0]`, and samples `SDRAM_nCS/nWE/nRAS/nCAS/CKE/CLK`). Model: on RAS latch row+bank; on CAS latch column; on WE (with nCS low) write DQ to `[bank][row][col][byte-half]`; on read drive DQ after 2-cycle CAS latency. Storage: `reg [15:0] mem [0:1][0:8191][0:63];` (2MB). Initialize all zeros.

```verilog
module sdram_model (
    inout  wire [15:0] SDRAM_DQ,
    input  wire [12:0] SDRAM_A,
    input  wire        SDRAM_DQML,
    input  wire        SDRAM_DQMH,
    input  wire [1:0]  SDRAM_BA,
    input  wire        SDRAM_nCS,
    input  wire        SDRAM_nWE,
    input  wire        SDRAM_nRAS,
    input  wire        SDRAM_nCAS,
    input  wire        SDRAM_CKE,
    input  wire        SDRAM_CLK
);
    reg [15:0] mem [0:1][0:8191][0:63];
    reg [12:0] row_latched;
    reg [1:0]  bank_latched;
    reg [10:0] col_latched;   // A[10:2] per controller (chip uses A[5:0]+A[1:0]; model decodes A[10:2] fully so aliasing matches the real chip's ignored-high-bits behavior ONLY if we decode A[5:0] — see note)
    reg [9:0]  cas_lat;

    // NOTE (critical): the physical chip decodes column = A[5:0], byte = A[1:0];
    // A[10:6] is ignored. To model aliasing correctly, use ONLY SDRAM_A[5:0] as
    // column and SDRAM_A[1:0] as byte-half select. Do NOT index with A[10:2].
    wire [5:0] col  = SDRAM_A[5:0];
    wire [1:0] byts = SDRAM_A[1:0];

    always @(posedge SDRAM_CLK) begin
        if (!SDRAM_nRAS && !SDRAM_nCS) begin
            row_latched  <= SDRAM_A[12:0];
            bank_latched <= SDRAM_BA;
        end
        if (!SDRAM_nCAS && !SDRAM_nCS) begin
            col_latched  <= SDRAM_A[10:2]; // kept for debug; unused in addressing
            cas_lat      <= 9'd2;
        end else if (cas_lat > 0) cas_lat <= cas_lat - 1;

        if (!SDRAM_nWE && !SDRAM_nCAS && !SDRAM_nCS && cas_lat == 0) begin
            // write: byte-half select A[1:0]=2'b10 per controller => high byte of word? 
            // rtl/sdram.sv drives {DQMH,DQML}=A[12:11] as masks and A[1:0]=2'b10;
            // dout = save_addr[0] ? data[15:8] : data[7:0]. Model: low byte <- DQ[7:0] when byts==2'b10? 
            // RESOLVE EMPIRICALLY in Step 4 alias test (write known pattern, read back);
            // initial guess: store full 16-bit word, expose both halves.
            mem[bank_latched][row_latched[12:0]][col] <= SDRAM_DQ;
        end
    end

    assign SDRAM_DQ = (!SDRAM_nCAS && !SDRAM_nCS && cas_lat == 0 && SDRAM_nWE) ?
                      mem[bank_latched][row_latched[12:0]][col] : 16'bZ;
endmodule
```

The byte-half mapping (A[1:0]=2'b10 fixed, controller selects `data[7:0]` vs `[15:8]` via `save_addr[0]`) must be resolved so that a write of byte X at logical address A reads back X. Step 4's alias test catches a wrong mapping immediately; adjust the model (not the RTL) until readback matches.

```systemverilog
// Stream one 16K block of `data` starting at file offset off via host path (index 0)
task load_rom_block(input [23:0] off, input [7:0] data[0:65535]);
    @(posedge clk_sys);
    tb_ioctl_index   = 8'd0;
    tb_ioctl_addr    = off[24:0];
    for (int b = 0; b < 16384; b++) begin
        tb_ioctl_download = 1; tb_ioctl_wr = 1; tb_ioctl_dout = data[b];
        @(posedge clk_sys);
        tb_ioctl_wr = 0;
    end
    tb_ioctl_download = 0;
endtask

// Force a single SDRAM read at logical address, return data (after ready)
task probe_read(input [24:0] la, output [7:0] d);
    @(posedge clk_sys);
    force dut.ram_addr = la;
    force dut.ram_rd   = 1'b1;
    repeat (8) @(posedge clk_sys);
    wait (dut.ram_ready === 1'b1);
    d = dut.ram_dout;
    force dut.ram_rd = 1'b0;
    release dut.ram_addr;
endtask

// Press a PS2 key: code = scancode, ext = extended prefix
task press_key(input [7:0] code, input ext = 1'b0);
    @(posedge clk_sys);
    tb_ps2 = {1'b1, 1'b1, ext, code};   // event=1, press=1
    repeat (20) @(posedge clk_sys);
    tb_ps2 = {1'b0, 1'b1, ext, code};   // edge again clears event latch
endtask
task release_key(input [7:0] code, input ext = 1'b0);
    @(posedge clk_sys);
    tb_ps2 = {1'b1, 1'b0, ext, code};
    repeat (20) @(posedge clk_sys);
    tb_ps2 = {1'b0, 1'b0, ext, code};
endtask
```

- [ ] **Step 2: Build script**

Create `tools/build_boot_rom.py`:

```python
#!/usr/bin/env python3
"""Assemble boot.rom for the ZX Spectrum MiSTer core (Scorpion extension).

Modes:
  --base <existing boot.rom>   append 4 Scorpion pages to a real release ROM
  --synthetic                  192KB of per-chunk patterns + real Scorpion pages
Outputs SHA1 per 16K chunk and full-file SHA256.
"""
import argparse, hashlib, sys

def sha1(b): return hashlib.sha1(b).hexdigest()

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--base", help="existing 192KB boot.rom to extend")
    ap.add_argument("--synthetic", action="store_true")
    ap.add_argument("--scorp", default="tools/scorp294.rom")
    ap.add_argument("-o", "--out", required=True)
    a = ap.parse_args()

    scorp = open(a.scorp, "rb").read()
    assert len(scorp) == 0x10000

    if a.base:
        base = open(a.base, "rb").read()
        assert len(base) == 0x30000, f"base must be 192KB, got {len(base)}"
    elif a.synthetic:
        base = bytearray()
        for i in range(12):  # 12 x 16K patterned chunks
            base += bytes([(i * 7 + o) & 0xFF for o in range(0x4000)])
        base = bytes(base)
    else:
        sys.exit("need --base or --synthetic")

    out = base + scorp  # chunks 16..19 at file offsets 0x30000..0x3FFFF
    open(a.out, "wb").write(out)
    for i in range(len(out) // 0x4000):
        c = out[i*0x4000:(i+1)*0x4000]
        print(f"chunk {i:2d} @0x{i*0x4000:05X}: sha1={sha1(c)}")
    print("full sha256:", hashlib.sha256(out).hexdigest())

main()
```
